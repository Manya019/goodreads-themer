# Goodreads Glass Theme

A browser extension that themes Goodreads and adds optional book-list views, filters, and cover-color accents.

## Install

1. Download and unzip this project.
2. Open `chrome://extensions` (or your browser's extensions page) and enable Developer mode.
3. Choose **Load unpacked** and select this folder, which contains `manifest.json`.

## Privacy

Settings, your optional Goodreads user ID, and cached book and cover-color data are stored in your browser. The extension reads your Goodreads shelves using your signed-in session and fetches cover images from their image hosts. It does not use analytics or a project-controlled server.
